#### One item, one quantity, one call

A call contains one node's text or one edge's — never two subjects, never the other pass's quantity. The item's class determines the instruction as it determines the ids: a claim is asked whether its statement is fixed, consistent and single-sensed, an analysis or an experiment whether its method establishes what it sets out to, and neither is asked the other's question. The item text is limited to the subject: a node's title and statement ([§10](../../10-metadata-format-version/statements-and-anchors.md)), or an edge's two statements and its authored context; a summary page is never read. The input guard refuses, before the call, a text containing a scoring token (`- rigor:`, `- strength:`, `(bearing …)`, `(strength …)`) or the template wrapper's own structure (a line opening `## Source:`, `## Target:` or `## Context`, or a run of twelve backticks), naming the document and line, and that item is `failed` with no call made.
