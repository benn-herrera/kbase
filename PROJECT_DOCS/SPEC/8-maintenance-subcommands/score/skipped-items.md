#### Skipped items

A value whose record is `manually-scored: true` ([§10](../../10-metadata-format-version/provenance-and-the-judged-hash.md)) is a person's judgement and stays. `--rescore-manual` reaches it: a full run with the flag also scores every manually scored item of its pass, and a `--node` or `--edge` naming a manually scored item is refused without it. The flag is read from the KB the run loaded at its start. A full run without it reaches a stale manually scored item and skips it: no model call is made for the item and nothing is written for it, and its ledger line records status `skipped`, reason `manually-scored`, with no value, charges or call, and so no capture. It counts under `counts.skipped`, never under `scored` or `failures`, and does not make `resume` present. A value `--rescore-manual` re-judges is written with the flag `false`, so later runs re-judge it too. `run.yaml` records the flag (`rescore_manual: true`), and `--resume` continues the run with it, appending no second `skipped` line for an item; a resume's recomputation of values under the current weights leaves a skipped item's line as it is. A `--dry-run` lists the stale manually scored values it would skip under `skip`, counted under `counts.skipped`.

An item whose node or edge is no longer in the KB — found when the results are written or when a resume reaches it — is skipped too, once, counted the same way: its line records status `skipped`, reason "the node or edge is no longer in the KB; its value is discarded and a resume does not ask it again", and no model call is made or value written for it.
