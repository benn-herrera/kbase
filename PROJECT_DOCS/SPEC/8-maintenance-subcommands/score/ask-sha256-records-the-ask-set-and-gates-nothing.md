#### `ask_sha256` records the ask set and gates nothing

It is one digest over every instruction the run can send, each rendered for an empty subject and concatenated in a fixed order — a rigor run's statement instruction and then its method one, a bearing run's one, an all-pass run's statement, method and then bearing instruction — so every fixed byte of a run's instructions is certified and nothing that varies with an item is. Each instruction is rendered as a first ask, and then, for each refusal case in turn, as a re-ask whose correction quotes no reply line and as one whose correction quotes the reply's lines ([A refused reply: one re-ask, then failed](a-refused-reply-one-re-ask-then-failed.md)), the correction's numbers, id and quoted lines empty in each. Each ledger line records its own item's prompt digest beside it, which is what names the variant that judged that item. `--resume` refuses a ledger for another KB root or format. It first writes and records every answer a stopped invocation left in an answer file — a value a person has set since is kept — then skips every item the ledger records `done`, and retries the `failed` ones. A run resumed after an update continues and checks no versions: one whose `ask_sha256` differs, or which has none, is run under the running templates, and the header keeps the digest the run began under. Where the running table for a written line's class gives its recorded ids a different value, the resume recomputes it, writes the changed value through the same path a run's results take — before the line records it — and leaves `repriced.yaml` in the run's directory naming each line that changed, the value it held and the value it took. An id that line's class's table no longer holds charges nothing, so a recomputation can raise a value. A recomputation that changes nothing records nothing and writes nothing. A run given no `--resume` is a new run over its own scope; what is stale is the judged hash's to say ([§10](../../10-metadata-format-version/provenance-and-the-judged-hash.md)), and the ledger of an earlier run is no evidence about it.
