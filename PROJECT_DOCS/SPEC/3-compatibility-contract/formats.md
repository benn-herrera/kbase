### Formats

A new KB is written in the current metadata format, `4.0.0`
([page §1.8](../../../NEW_MCP_CLI_DESIGN/1-model/1.8-format-version.md), [§10](../10-metadata-format-version/index.md)). A KB in a superseded form,
`3.0.0`, `2.0.x` or `1.0.0` ([§10](../10-metadata-format-version/index.md)), is read through migration.

**Theorem numbering** is whatever pandoc prints.
