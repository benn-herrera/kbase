### The configure commands' write location

`configure-providers` and `configure-models` write one layer's directory:

- Without `--layer`, a command writes the directory `--config-dir` or `$KBASE_CONFIG_DIR` names, whether or not it exists, the flag before the variable; else `~/.config/kbase`, even where a repository's `.kbase/` exists. `--layer global` writes `~/.config/kbase` and `--layer repository` writes `<repository>/.kbase`; an explicit `--layer` outranks the variable.
- A `--layer` other than `global` or `repository` is a usage refusal keyed `--layer`, `allowed` those two. `--layer` beside `--config-dir` is a usage refusal keyed `--layer`. `--layer repository` outside a worktree is refused with `check: worktree`, `path` the directory the search started from, and `git init` as the remedy. An empty `--layer` on the command line counts as none given; over MCP an empty `layer` is a value outside the enum ([§11](../11-the-mcp-server/tools.md)).
- `configure-providers`' `layer` names the layer written: `global`, `repository`, `explicit` or `environment`; `global` and `repository` are the values `--layer` takes.
- The stack a command writes into is the layer it writes and the layers beneath it: the global layer is beneath the repository layer, and nothing is beneath any other layer. The command reads that stack only.
- `configure-providers` creates `providers.toml` where absent, containing its comment header, an example entry commented out, and the entry written, and no other entry. `configure-models` creates `config.toml` where absent from its commented template: comments that explain the file and guide the `[models]` ids (the guidance `kbase://model-hints` serves, [§11](../11-the-mcp-server/resources.md)), an empty value for each role it is not given (which parses as unset), and `[asks]` and `[sampling]` commented out. Each otherwise edits the file under [§9.5](9.5-the-configure-commands-targeted-update-byte-preservation-contract.md). A refusal writes nothing, and so does a `configure-models` catalogue failure.
