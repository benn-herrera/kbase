## Plan & Execute Process

The process is the `dev-process` skill's; this section states the rules kbase adds to it. Its
terms' bindings sit with their subjects ([Build and Run](../build-and-run/index.md) binds the gates).

- **A post-plan review includes the MCP surface where the plan changed it.** In a separate step, the
  `architect` reviews the output of `just measure-mcp-surface` for bloat, redundancy, user friction
  and general rot. A plan that changes nothing MCP serves — its tools, instructions and help
  resources — never triggers it.
