The kbase skill carries the workflow; show-config reports how provider and model configuration resolves. A tool's full help is the resource kbase://help/<tool>. kb-root/.index/ holds kbase's own records, and the claim-graph sheets (claim-graph.svg, claim-graph-digest.svg, a volume's claim-graph.svg) and every .dot file are kbase's derived output: never read or write any of them. The query tools, show, deps, find, stats and the rest, report what the records hold; the write tools change them; refresh and render-claim-graph write the sheets. Testing that one of these paths exists (test -d, a stat) is allowed; listing, globbing or opening anything under kb-root/.index/ is reading it. A claim-rigor.md page is the exception: refresh generates it for reading as prose; take values from the query tools, never from it, and never edit it.
