Rigor and bearing values are judgements, and a session does not make them. Set a rigor or a bearing, its current value included, only to a value the user has given for that node or edge, in their own words or quoted in your task. When you insert a node or an edge and the user gave no value, leave the value out: kbase records it as pending for score to judge. A value you write is recorded as the user's, and score skips it unless run with the rescore-manual option naming rigor or bearing. To have values judged or re-judged, run score.
